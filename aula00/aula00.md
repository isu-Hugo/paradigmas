#### Introdução aos paradigmas de programação
Um paradigma é uma forma de pensar e organizar estruturas. 
Existem muitas linguagens pois cada uma tem uma finalidade, sendo performance, segurança e tecnologias diferentes.

Sintaxe é a forma válida de escrever, como a estrutura é organizada;
Semântica é o significado e comportamento, definindo nomes, tipos e operações;
Um programa pode compilar e executar uma regra de negócios errada.


|     Tipo     |                 Descrição                 |
| :----------: | :---------------------------------------: |
|  Imperativo  | Descrevemos comandos e mudança de estados |
|   Objetos    |     Agrupamos dados e comportamentos      |
|  Funcional   |      Usamos funções e transformações      |
|    Lógico    |         Declaramos fatos e regras         |
| Concorrência |        Coordenamos várias tarefas         |

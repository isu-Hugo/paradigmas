1. A genealogia das linguagens não é uma escada de progresso. Explique essa afirmação e apresente dois fatores históricos que fazem uma linguagem influenciar outra sem necessariamente substituí-la.
R: A evolução das linguagens não acontece como uma escada, onde uma linguagem nova simplesmente substitui a antiga. Cada linguagem surgiu para resolver determinados problemas ou atender a uma necessidade diferente. Por exemplo, o Fortran foi criado principalmente para cálculos científicos, enquanto o Lisp tinha mais foco em processamento simbólico. Mesmo com linguagens novas aparecendo, as antigas podem continuar sendo usadas quando ainda atendem bem determinado tipo de problema. Por isso, é melhor pensar na evolução das linguagens como vários caminhos diferentes que foram surgindo e influenciando uns aos outros.

Ortogonalidade é quando os recursos de uma linguagem podem ser combinados de uma forma mais regular, sem muitas exceções. Isso normalmente facilita o entendimento da linguagem. 11 Construa uma cadeia de influência que passe por ALGOL, Pascal e C. Depois contraste essa linhagem imperativa com a proposta declarativa de Prolog.
R: ALGOL 60 teve bastante influência sobre várias linguagens imperativas. Pascal, por exemplo, recebeu forte influência do ALGOL e foi criada buscando uma linguagem mais simples e organizada. Já C veio de outra linha de desenvolvimento, passando por linguagens como CPL, BCPL e B, então não é correto dizer simplesmente que C veio do Pascal. O Prolog já segue outro caminho, porque é uma linguagem lógica e declarativa. Enquanto Pascal e C normalmente dizem ao computador quais passos executar, no Prolog o programador trabalha com fatos e regras e o sistema procura uma solução usando esses conhecimentos.

12 Modele em linguagem natural uma pequena base Prolog com dois fatos, uma regra e uma consulta. Explique por que isso representa programação lógica, não apenas armazenamento de dados.
R: Podemos imaginar uma base em Prolog com alguns fatos, como “Maria é mãe de João” e “João é pai de Pedro”. Depois podemos criar uma regra dizendo que uma pessoa é avó quando é mãe ou pai de alguém que também é pai ou mãe de outra pessoa. Assim, podemos fazer uma pergunta como “Maria é avó de Pedro?” e o Prolog tenta encontrar uma resposta usando os fatos e as regras existentes. Isso mostra bem a ideia da programação lógica, porque não precisamos escrever todos os passos para chegar à resposta.

15 A primeira aplicação de Java não foi a Web, mas a Web impulsionou sua adoção. Explique como mudanças de contexto podem reposicionar uma linguagem.
R: Java não foi criada originalmente para a Web. Ela surgiu pensando em dispositivos eletrônicos e na necessidade de uma linguagem mais simples e confiável do que C e C++. Depois, com o crescimento da Web, os applets Java começaram a ser usados dentro das páginas dos navegadores. Isso fez com que Java ganhasse bastante popularidade. Ou seja, a linguagem acabou encontrando uma aplicação diferente daquela que tinha sido pensada originalmente e suas características de portabilidade e segurança ajudaram bastante nesse processo.

18 Diferencie XSLT e JSP quanto a entrada, processamento e saída. Por que ambas podem ser chamadas de linguagens híbridas de marcação e programação?
R: XSLT e JSP misturam textos de marcação com programação real, mas trabalham de modos diferentes na prática. No XSLT, a entrada é um arquivo de dados XML junto de uma folha de estilos XSLT, o processador busca padrões no documento usando templates e a saída final é um novo arquivo formatado, normalmente em HTML ou outro XML. Já no JSP, a entrada é uma página com tags HTML misturadas com código Java, onde o servidor processa e transforma esse arquivo em um servlet Java para executar a lógica no backend, gerando como saída o código HTML puro que é enviado ao navegador. Ambas são chamadas de linguagens híbridas de marcação e programação justamente porque não são documentos estáticos comuns, mas sim arquivos com tags que contêm instruções executáveis como testes condicionais com <if> e laços de repetição.
